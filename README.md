### Проекты

**[ND-Screen](https://github.com/arphset/ND-Screen)** · [демо](https://nd-screen.vercel.app)
Система скрининга признаков РАС и СДВГ у взрослых на основе самоотчёта.
- Объединил содержание семи психометрических опросников (RAADS-R, AQ, CAT-Q, ASRS и др.) и сопоставил ответы с критериями DSM-5-TR.
- Разработал многоуровневую модель оценки: балл вопроса → критерий → итоговый индекс 0–100, с поправкой на маскировку и интервалами неопределённости.
- Реализовал проверку согласованности ответов и пересчёт результатов в шкалы исходных тестов.

`JavaScript` `психометрия` `модели оценки`

**[QualityJPG](https://github.com/arphset/QualityJPG---Made-in-Abyss)**
Информационная система оценки качества фотографий товаров для маркетплейсов.
- Выставляет объяснимую оценку по резкости, экспозиции и композиции: лапласиан, градиент Собеля, анализ гистограммы, детекция товара YOLOv8.
- Формирует рекомендации по исправлению с помощью локальной LLM (Ollama).
- Включает панель администратора со статистикой проверок, хранение данных в PostgreSQL и 43 автотеста.

`Python` `OpenCV` `YOLOv8` `PostgreSQL` `Streamlit` `Docker`
